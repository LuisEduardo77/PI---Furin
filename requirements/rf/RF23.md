# RF23 — Exibir aviso quando a leitura falhar, orientando a tentar de novo ou procurar o ATE

| Campo | Valor |
|---|---|
| **Documentação** | Revisada em 21/10/2026 (DEC-37 a DEC-39) |
| **Implementação** | Planejada |
| **Grupo** | Alunos |
| **Atualizado em** | 21/10/2026 |

## Objetivo

Orientar o aluno quando a leitura não for aceita e dar ao funcionário o motivo para resolver,
sem expor ao público se um código existe nem por que foi recusado.

## Descrição

Quando uma leitura é recusada:

- o **monitor do aluno** mostra sempre a **mesma mensagem genérica**;
- o **painel do funcionário** mostra o **motivo** (RN09).

Nada é gravado em `registro_acesso`. O evento vai para o log.

genérica para o aluno e detalhada para o funcionário.

correto é RF22/RF23 ([rastreabilidade §7.4](../../docs/rastreabilidade.md)).

## Perfis envolvidos

- **Aluno:** vê o aviso genérico.
- **Funcionário:** vê o motivo e ajuda o aluno.

## Pré-condições

Uma leitura foi enviada pela portaria (RF09/RF14) e o servidor a recusou.

## Fluxo principal

1. O servidor identifica o motivo da recusa (RN09):

   | Motivo | Painel do funcionário |
   |---|---|
   | Conteúdo lido fora do formato (diferente de 32 caracteres hexadecimais) | "Leitura não reconhecida. Tente novamente." |
   | Código não encontrado | "Código não reconhecido." |
   | Carteirinha revogada ou expirada | "Carteirinha revogada/expirada. Emitir segunda via." |
   | Aluno inativo ou sem turma vigente | "Aluno inativo / sem turma vigente." |
   | Saída pendente de dia anterior (DEC-28, A5) | "Saída pendente de DD/MM: registre a saída manual antes da nova entrada." |
   | Erro inesperado no servidor | "Não foi possível registrar. Tente novamente ou use o registro manual." |

2. O **monitor do aluno** mostra, em todos esses casos:
   > "Não foi possível ler sua carteirinha. Tente de novo ou procure o funcionário da
   > portaria." (A11 p.8)
3. A mensagem do painel do funcionário fica em `role="alert"`. A do monitor do aluno fica na
   região própria dele. Nenhuma das duas move o foco do campo de leitura (A11 §5.13.8).
4. O evento `LEITURA_RECUSADA` vai para o log com o motivo e o horário. O código lido
   **não** vai inteiro para o log Só os **4 primeiros caracteres** são registrados (DEC-28, A12).
5. Depois de **4 s** (PEND-12, DEC-28), o monitor volta à espera.
6. Se precisar, o funcionário faz um registro manual (RF12) ou emite uma segunda via (RF07).

## Exceções e mensagens

| Situação | Comportamento |
|---|---|
| Leitura repetida em até 2 s (RN03) | **Não** é falha. O funcionário vê "Leitura já recebida" e o monitor não muda |
| Outra liberação em curso (RN05) | **Não** é falha. O monitor mostra "Aguarde." |
| Várias falhas seguidas do mesmo código | Cada uma é tratada e registrada no log. Limite ou alerta específico: fora do MVP |

## Dados utilizados

| Dado | Uso |
|---|---|
| Código lido | Validação de formato e busca em `carteirinha` |
| `carteirinha.revogada_em`, `expira_em` | Validade |
| `aluno.ativo`, `vinculo_turma` vigente | Situação do aluno |
| Log de auditoria | `LEITURA_RECUSADA` |

## Regras de negócio relacionadas

- **RN09** (leitura inválida).
- **RN06** (pendência).
- **RN17** (exposição mínima).

## Critérios de aceitação

| ID | Critério |
|---|---|
| CA-RF23-01 | Para cada motivo da tabela, o monitor do aluno mostra **exatamente** a mesma mensagem genérica de A11 p.8 |
| CA-RF23-02 | O painel do funcionário mostra o motivo específico de cada caso |
| CA-RF23-03 | Nenhuma leitura recusada cria registro em `registro_acesso` nem notificação |
| CA-RF23-04 | Uma leitura com conteúdo fora do formato (por exemplo, "abc" ou 40 caracteres) é recusada como "Leitura não reconhecida", sem consultar o aluno |
| CA-RF23-05 | A mensagem do funcionário é anunciada como alerta, e o foco continua no campo de leitura (A11 §5.13.8) |
| CA-RF23-06 | O monitor do aluno não indica se o código existe nem o motivo da recusa (A09 art. 17) |
| CA-RF23-07 | O evento `LEITURA_RECUSADA` vai para o log com o motivo e sem o código completo |
| CA-RF23-08 | O texto "Leitura não reconhecida" aparece mesmo sem cores (A11 §5.11.1) |
