# RF11 — Buscar aluno por nome ou matrícula

| Campo | Valor |
|---|---|
| **Documentação** | Revisada em 21/10/2026 (DEC-37 a DEC-39) |
| **Implementação** | Planejada |
| **Grupo** | Portaria e Cadastro |
| **Atualizado em** | 21/10/2026 |

## Objetivo

Permitir que o funcionário encontre um aluno com rapidez:

- para o registro manual, quando o aluno está sem a carteirinha (RF12);
- para abrir o cadastro do aluno (RF08).

## Descrição

O funcionário digita parte do nome ou a matrícula, e o sistema lista os alunos encontrados.
Cada resultado mostra nome, matrícula, turma e situação, e traz ações com nomes
acessíveis, como "Registrar manualmente para Ana Teste" e "Editar aluno Ana Teste".

## Perfis envolvidos

**FUNCIONARIO.**

## Pré-condições

O funcionário está autenticado. Ele faz a busca pela tela **Portaria → Registro manual** ou
pela tela **Alunos**.

## Fluxo principal

1. O funcionário digita o termo no campo "Buscar aluno por nome ou matrícula" e aciona
   **Buscar**.
2. O servidor:
   - tira os espaços das pontas do termo;
   - se o termo tem só dígitos, procura por **matrícula** igual ou que começa pelo
     termo (DEC-28, C4);
   - nos demais casos, procura pelo **nome** que contém o termo, sem diferenciar
     maiúsculas, minúsculas e acentos (collation `utf8mb4_0900_ai_ci`).
3. A consulta é parametrizada. Os caracteres especiais de `LIKE` (`%`, `_`) são
   tratados como texto (A10 §8.28).
4. O servidor devolve no máximo **20** resultados (DEC-28, C4), em ordem de nome.
   Cada resultado tem:

   | Coluna | Exemplo fictício |
   |---|---|
   | Nome | Ana Teste |
   | Matrícula | 000123 |
   | Turma | 6A — Manhã |
   | Situação | Na escola / Fora da escola / Inativo |
   | Ações | "Registrar manualmente para Ana Teste" (portaria) · "Editar aluno Ana Teste" (alunos) |

5. Uma mensagem de status anuncia "3 alunos encontrados", sem mover o foco
   (A11 §5.13.8).
6. O funcionário escolhe uma ação. Os dados do aluno escolhido seguem para a próxima tela (RF12
   ou RF08), sem precisar digitar de novo (A11 §5.9.15).

### Escopo dos resultados [DEC-28, C4]

| Origem da busca | Alunos incluídos |
|---|---|
| Registro manual (portaria) | Só **ativos** |
| Tela Alunos | Ativos e, com o filtro "Incluir inativos", também os inativos |

## Exceções e mensagens

| Situação | Mensagem |
|---|---|
| Termo vazio | "Digite o nome ou a matrícula do aluno." |
| Termo curto demais (menos de **2** caracteres, DEC-28) | "Digite pelo menos 2 caracteres do nome." [PROP: texto] |
| Nenhum resultado | "Nenhum aluno encontrado para 'Xyz'. Confira o nome ou a matrícula." |
| Mais resultados que o limite | "Mostrando os 20 primeiros resultados. Refine a busca." [PROP: texto] |

## Dados utilizados

| Dado | Campo |
|---|---|
| Nome | `aluno.nome` |
| Matrícula | `aluno.matricula` |
| Turma | `vinculo_turma` vigente → `turma` |
| Situação na escola | Calculada pela RN12 (última movimentação confirmada) |
| Ativo/inativo | `aluno.ativo` |

**Não são mostrados:** foto, contato e dados do responsável (minimização, A10 §5.34).

## Regras de negócio relacionadas

- **RN12** (situação "Na escola" ou "Fora da escola").
- **RN07** (registro manual, que usa a busca).

## Critérios de aceitação

| ID | Critério |
|---|---|
| CA-RF11-01 | "ana" encontra "Ana Teste" e também "Ána" (sem diferenciar caixa e acento) |
| CA-RF11-02 | "000123" encontra o aluno da matrícula 000123. "123" **não** confunde zeros à esquerda com outra matrícula (busca por prefixo, DEC-28, C4) |
| CA-RF11-03 | Um termo com `%` ou `_` é buscado como texto, sem virar curinga, e não causa erro (teste de injeção, A10 §8.28) |
| CA-RF11-04 | Na portaria, alunos inativos não aparecem. Na tela Alunos, aparecem só com o filtro "Incluir inativos" |
| CA-RF11-05 | Os resultados não mostram foto nem dados do responsável |
| CA-RF11-06 | Cada ação da lista tem um nome acessível com o nome do aluno ("Registrar manualmente para Ana Teste") (A11 §5.13.7, §5.13.10) |
| CA-RF11-07 | A quantidade de resultados é anunciada por `role="status"` sem mover o foco. Os resultados são navegáveis só com teclado |
| CA-RF11-08 | Sem login, a busca leva à tela de login |
